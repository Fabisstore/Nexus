# Nexus V28 – Homeoffice Ausbau

Nexus Homeoffice ist als geschützte Nexus-Plus-Kachel auf der Startseite eingebunden. Ohne bestätigte Plus-Freischaltung passiert beim Klick nichts. Mit Plus öffnet sich der Editor.

Enthalten: Formatierungen, Schriftarten/-größen, Farben, Listen, Ausrichtung, Einzüge, Hoch-/Tiefstellung, Links, Bilder, Tabellen, Seitenumbrüche, Suche/Ersetzen, Wort-/Zeichenzähler, Auto-Speichern, Strg+S, Dokument löschen, HTML-/TXT-Export sowie Drucken/PDF.

Die serverseitige Plus-Prüfung bleibt bestehen; Office-Dokumente werden nur für berechtigte Nutzer über Supabase gespeichert.
