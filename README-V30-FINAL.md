# Nexus V30 – Final UI & profile update

## This update includes
- YouTube-style blue verification badge for Nexus Plus/owner accounts.
- Real profile-picture upload to Supabase Storage, plus remove/URL fallback.
- More profile fields: status message and pronouns.
- Profile pictures and verification badge in friends, search, communities and call lists.
- Calls opens as a contact/history lobby; it does not immediately show Join/End controls.
- Homeoffice redesigned as a Word-like workspace with A4 paper, normal/lined/grid pages and automatic page continuation.
- Plus designs now change the app's layout/surfaces as well as colors.
- More realistic desktop collaboration-app layout with navigation rail, richer cards, glass surfaces and spacing.

## SQL
Run `supabase-v30.sql` in Supabase SQL Editor after the previous migrations.
